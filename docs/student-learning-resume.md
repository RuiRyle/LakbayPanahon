## Chapter challenge resume

Partial chapter inputs now include their question ID. Restore applies them only to that question; submitted answers and position remain separate. Advancing clears choice, matching and trade state before saving the next question. Older drafts without the partial-question marker preserve submitted answers but reset partial inputs once. The expanded chapter Chrome check verifies mismatched input rejection and clean next-question snapshots alongside valid partial restoration.

An owner-only `chapter` draft uses the chapter ID as its scope and a null mission ID. It stores submitted answers, question position and partial selected choice/matching/trade state. Challenge content/policy must match before restoration. The score is recalculated from submitted answers rather than trusting a saved score. Resume does not itself grant completion or a badge; the existing submission service remains responsible for that transaction.

The dashboard offers Resume Chapter Challenge for the current eligible chapter. Successful completion clears the draft; failed completion saves can be retried with the restored answers. Failed challenge results can also be reconstructed from the completed answer set. A retry starts fresh answers and updates the draft. Shared saving/retry/leave protection applies. Rules supporting chapter-scoped drafts are deployed.

Expanded chapter Chrome checks restore partial choice, matching and trade inputs before submissions and retain failure/retry, badge replay and session-recovery checks. Dashboard Chrome checks verify its resume action; 13 focused continuation/draft/journey tests pass. Full live UI and physical-phone acceptance remain deferred; Hosting was not deployed.

## Restarting practice and chapter challenges

Resumed practice offers confirmed Start Practice Over. It clears only the unfinished draft and starts a fresh session; saved history remains. Its control is hidden during completion saving. Resumed chapter challenges offer confirmed Start Challenge Over, clearing the unfinished draft/interface and returning to challenge entry. Saved completion and badges remain untouched. Chapter restart is blocked during loading/result saving. Failed draft deletions keep current work available with a retry message. Expanded practice/chapter Chrome checks exercise both reset paths with the real shared confirmation control.
