# Evidence-supported chapter investigation

The first prologue chapter-challenge question now asks students to choose a lesson clue and a conclusion together. The problem concerns the north-south relationship between Cebu City and Davao City. Three source cards come directly from active Firestore `storyScenes.exploreItems`; they are not hardcoded browser explanations. One directly supports the direction claim, while the others address resources and map limitations.

Saved journal references are marked **Saved in your journal**. Every student can read the same evidence regardless of whether they saved it earlier. A journal link opens a separate tab without leaving the challenge. The journal is a reference aid, not a prerequisite, extra reward, or source of automatic credit. An optional journal-read failure leaves the activity usable. Missing required lesson evidence disables submission and offers a retry.

The student selects both a clue and a conclusion, using two labelled native selects. Both must be correct for this question's single point. It uses the existing historical-decision question with optional `evidenceTask` metadata. The stored answer is `{gameType: 'evidenceDecision', evidenceId, conclusion}`. The UI score, restored score, shared reward grading and final learning review all account for both parts. Drafts preserve the two selections through reload and failed evidence loading. Correctness feedback appears in the final challenge review rather than supplying the answer before submission.

Only `chapterChallengeQuestions/challenge-prologue-question1` was changed in the original Firestore project. `data/evidence-challenge-pilot.json` contains the guarded update, and `functions/apply-evidence-challenge.cjs` supports read-only preflight or backed-up, atomic `--apply` with readback verification. Ten questions, the 70% passing rule, badge identity and zero additional chapter XP remain unchanged. No existing student completions were migrated. Content-version changes can restart an unfinished challenge under the existing draft policy.

The website changes are in `js/evidence-decision.js`, `js/chapter-challenge.js`, `js/student-rewards-client.js` and `css/chapter-challenge.css`.
