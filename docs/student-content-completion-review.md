## Reference limits

Plasencia is a translated 1589 colonial missionary account in a particular Tagalog setting, not a neutral description of every society or proof of fictional village events. National Museum Ritual Objects describes named ethnolinguistic examples and traded stoneware; ethnographic examples must not be assigned one ancient start date. The Bangsamoro overview supports Sulu context; its official indexed record was accessible while direct access returned 403.
