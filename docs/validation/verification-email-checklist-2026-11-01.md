Prepared 1 November 2026. **No real-inbox test has been performed.** Existing hosted qualification tests set verified email through trusted Auth administration for temporary synthetic identities; they did not send or inspect email.

An adult operator/reviewer should use an inbox they control and the normal teacher application page:

1. Confirm the preview URL is still active in current release status, or use the reviewed local server with an authorized return domain.
2. Register/sign in and open Teacher Application. Check that the account starts without classroom access.
3. Choose Send Verification Email once. Check inbox/spam, sender presentation, readable instructions and the verification link. Do not paste the link, token, email address or password into this repository.
4. Open the link, then return to the original application tab and choose Check Email Status. Confirm the verified indication changes and unsaved form details remain.
5. Confirm email verification alone does not grant classroom access: qualifications still need submission and administrator review.
6. If delivery fails, record the date, browser, non-sensitive UI error and whether the request reported success. Do not repeatedly resend, manufacture successful results or change production email settings without diagnosis.
