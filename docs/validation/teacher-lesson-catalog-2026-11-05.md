# Teacher lesson catalog

Assigned Missions now provides an independent lesson browser before class creation. It uses the existing approved-teacher active mission/chapter catalog, with search across titles and goals, chapter filtering, eight-card pagination and authored discussion prompts when present. Empty or missing metadata states are explicit.

Preparing an assignment for a selected class fills the existing editor and honors unsaved-change confirmation. Without a selected class, the teacher chooses an active owned destination or creates a class. Destination URLs carry mission and class identifiers; publication still uses existing ownership and catalog validation. Browsing causes no learner progress/reward writes.

Desktop/mobile browser checks cover pre-class access, search and no matches, learning goals, receiving-class guidance and mission-editor preparation. Separate document tests check catalog initialization after authentication on the actual assignments destination. No rules or collection changes. Hosting remains local and unpublished.
