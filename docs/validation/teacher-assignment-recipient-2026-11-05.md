# Assignment receiving-class refinement

Assigned Missions supports composing before class creation/selection. Mission, instructions, optional due date and visibility remain unchanged when Receiving class changes. Save requires an owned active recipient. Missing-recipient attempts retain the prepared draft. Saved-record edits lock their original recipient; cancel returns to a new composer. Archived recipients are excluded from both announcement and assignment selectors.

Browser tests cover pre-class editing, missing-recipient preservation, audience preview, field preservation, cross-class saving and original-recipient locking at 390px/1280px. Existing deadline, publication, progress and teacher workflow checks remain passing. Separate teacher document navigation is also checked. No new schema or rule permission is introduced. Changes remain local and unpublished.
