# Student Progress refinement — November 5, 2026

The teacher Student Progress page now provides a clear classroom context, real joined-student/activity/review counts for the selected class, and a focused two-column student list without repeating the same classroom name on every row. Classroom choices have primary View students links and optional collapsed roster previews. Search, twenty-student paging and private membership controls remain available. Empty classrooms link directly to their own invitation/settings page; archived classes explain why reports are unavailable and offer their own settings link.

The open report is highlighted in the roster, exposes its expanded state to assistive technology, and clears that state when the teacher returns or changes context. Reports identify the student and classroom before the saved-learning snapshot, then show a suggested learning conversation. Guidance, private follow-up, history and export tools remain separately expandable. Repeated counts were moved into history, and mobile roster rows become stacked cards. Native report history tables retain their own overflow containers.

Student Progress loads mission/chapter labels without downloading the unrelated story-scenes catalog. Individual quiz/progress records are still loaded on demand when a report is opened. No invented class averages, ability labels or fake progress percentages were added. Existing authorization and data-retention behavior are unchanged.
