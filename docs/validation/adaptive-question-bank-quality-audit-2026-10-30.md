# Adaptive question bank quality audit — 2026-10-30

## Scope

This read-only audit checked the two local adaptive question manifests used for the 660-question publication: 10 Mission 1 items and 650 generated items for other missions. It checked required fields, answer-key values, distinct choices, explanation coverage, exact prompt duplication, answer-length outliers, and repeated generic wording in hard items. It did not independently assess historical accuracy, curriculum alignment, or Grade 5 readability.

The published-status audit separately confirmed 660 active question documents. This audit inspected the publication manifests, not all 660 live Firestore document bodies.

## Results

- **660 items:** 330 easy and 330 hard.
- **Structure:** zero missing required fields, invalid answer keys, duplicate choices within an item, or incomplete answer feedback.
- **Duplicate prompt:** one exact duplicate prompt appears in `chapter6-quiz1` (Legazpi local responses) and `chapter7-quiz4` (reduccion responses), both at easy difficulty.
- **Hard-item quality:** 325 of 330 hard items use the same generic keyed answer: “The note supports the point it states in this case; broader conclusions need more evidence.” Those same items also reuse generic distractors such as claims that one note answers every question or proves the opposite everywhere. This makes the keyed answer easy to spot and does not create a meaningful hard variant for the topic.
- **Answer-length cue:** one item has a keyed answer of 130 characters while every distractor is 66 characters or shorter. This is a review flag, not proof the key is wrong.

The 325 repeated-template items are the generated set for missions other than Mission 1. Mission 1's five hard items did not match that specific wording pattern.

As a temporary safeguard, new mission selection skips hard items whose keyed answer exactly matches the repeated template. The affected documents remain active in Firestore, but the client falls back to other available difficulty levels. A learner who already has a saved attempt can resume its existing question set. Replacements can restore hard-level selection after they pass the quality audit.

## Recommended correction

Replace or temporarily exclude the 325 repeated-template hard items. A replacement should test a topic-specific inference from the lesson evidence and use three plausible, topic-related distractors. Balance answer lengths and avoid using a generic evidence caution as the keyed answer in every item. Resolve the duplicate prompt and inspect the answer-length outlier at the same time.

Keep the easy items and current runtime logic unchanged during this content correction. Re-run the structural audit and verify each replacement was read back from Firestore before treating the corrected bank as live. A human educator review remains advisable for historical accuracy and curriculum fit; automated checks cannot establish those.

No Firestore content was changed during this audit.
