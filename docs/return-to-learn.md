# Return to Learn

The student Home page now offers a **Remember This** card for a topic from a completed mission. It presents one short recall question from the active Firestore practice bank, gives answer feedback, links to the relevant story topic, and offers targeted practice. It uses the learner's saved mission completion, quiz attempts, practice sessions, and authored active practice-question topics. No question text or topic label is built into the browser code. If no valid authored recall question is available, the lesson and practice links remain.

The interval is stored in `learningSettings/progression.reviewAfterDays`, currently 3. A topic becomes eligible when that many full days have passed since mission completion or its latest saved quiz/practice activity. The oldest eligible topic is shown first. After answering, **Another Memory Clue** offers the next due topic using the already loaded catalog. Completing practice on a topic postpones its next reminder. The single Home question is an immediate, unsaved check; saved learning evidence comes from the full practice activity. The feature is guidance only: practice does not add mission XP, repeat a badge, or claim durable mastery. `studentReviewEvents` stays reserved for actual story reviews.

The current Home data load adds one server read for the existing progression settings document. Question banks remain scoped to missions with saved quiz/practice history. If the setting or optional review evidence is unavailable, Home shows a retry message without inventing a due topic or blocking the main journey.

Publication: `node functions/setup-return-to-learn.cjs` previews the setting update; `--apply` makes a guarded field-only update with backup and readback. The original project's setting was published and verified on 29 October 2026. Frontend Hosting is still undeployed.

Eight focused local selection/link/feedback checks and the dashboard browser check passed. An authenticated Chrome walkthrough against the original project completed a first mission using a temporary account, aged only that account's completion and quiz attempt, then verified that Home showed an authored due topic, graded its one-question recall check, offered a different due clue, and provided the correct lesson/practice links. A recent practice record for that topic postponed it and Home offered another due topic. The test account and owned records were removed. This verifies the website behavior using synthetic dates; it does not establish how an individual learner responds after three actual days.
