# Retention and application pilot guide

Prepared 6 November 2026. **Draft, not validated.** This is a three-concept pilot, not an all-mission assessment or a claim of DepEd approval. No participants or teacher reviewer have yet been confirmed.

## What is ready

- student-form-A.md: initial concept check, before the selected learning.
- student-form-B.md: post-learning check using changed examples.
- student-form-C.md: delayed recall plus application to new examples.
- facilitator-answer-guide.md: separate expected reasoning, for adult review.
- scoring-template.csv: blank participant codes, evidence scores and administration conditions.

Prompts use explicitly invented examples so they do not present imagined events as Philippine history. Mission links map to current repository objectives: prologue-mission1 (map location/limits), prologue-mission3 (evidence context), chapter3-mission1 (boats, routes and evidence limits). A qualified teacher must check whether each form actually measures those objectives. These forms are drafts of parallel tasks; equivalent difficulty has not been established.

## Before use

Record the reviewer, review date and requested revisions. Check accuracy, age suitability, language accessibility, objective alignment, scoring criteria, and difficulty across forms. Pilot the wording with the intended age group under the study's approved arrangements. Revise the instruments before collecting final research results; do not change them mid-comparison without recording that change.

Decide and write down the delayed interval, response time, permitted assistance and lesson exposure before administration. Planned delay: ______ days. Time allowed: ______. Permitted assistance: ______. Do not infer an appropriate interval from software defaults. Record the actual interval for each participant.

Keep answer guidance separate from student sheets. Do not give corrective answers before a scheduled comparable check if that would change the planned conditions. If feedback or extra practice is given, record it; do not hide that exposure. Record whether the student had already studied these missions before Form A.

## Suggested administration

1. Use an anonymous participant code and administer Form A before the selected instruction. Record prior exposure and assistance.
2. Let the student complete the selected lesson activities. Record which missions were actually completed and any teacher support.
3. Administer Form B under the predetermined post-learning conditions. Record timing and assistance.
4. Administer Form C at the planned later interval, recording actual elapsed days and any intervening study, practice or guidance. It is not an immediate retry.
5. Score the claim, clue and connection separately. For Form C, score explicit recall separately from application to the new example.

Reading a prompt aloud may support access, but explaining which answer is correct changes the assessment conditions. Apply and record the chosen reading/language support consistently. Accept equivalent accurate wording; do not grade English fluency instead of the intended history reasoning.

## Draft analytic rubric

| Criterion | 0: not enough correct evidence | 1: developing | 2: clear |
| --- | --- | --- | --- |
| Claim | Incorrect conclusion or no interpretable claim in an attempted answer | Partly appropriate but incomplete or overgeneralized | Conclusion fits the given information and its limits |
| Clue | No relevant clue identified in an attempted answer | Relevant clue identified vaguely or partly | Specific relevant clue from the prompt identified |
| Connection | No valid connection in an attempted answer | Link between clue and claim is partial or implicit | Explains why the clue supports the claim, including a relevant limit where asked |
| Delayed recall (Form C only) | Recalled principle is absent/incorrect in an attempted answer | Partly recalls the principle | Accurately states the principle independently of the new example |

For A/B, application reasoning has a maximum of 6 per item: claim + clue + connection. Use the same three criteria for the application portion of C. C recall has a separate maximum of 2 per item. **Do not compare a C total including recall with an A/B total that excludes it.** Do not invent a passing threshold or mastery category.

An absent, skipped, unreadable or interrupted response remains missing with a recorded reason; do not silently convert it to zero. A stated 'I do not know' on an otherwise administered item can receive 0 with that response recorded. Score each criterion from actual response evidence, not confidence, speed or effort.

Before formal scoring, have reviewers independently score a small common set and discuss disagreements using the rubric. Preserve original ratings and how disagreements were resolved. No reliability coefficient or validated score is claimed by preparing these materials.

## Interpretation

Report sample size and missing responses for each stage, criterion results, conditions and actual delay. Initial-to-post changes are descriptive evidence for this pilot; without an appropriate study design they do not establish causation. Form differences and repeated exposure may affect results. Delayed recall is distinct from application, enjoyment and usability. This pilot does not establish learning across all 66 missions.

These materials are outside the public website package. They add no game XP, grade, unlock gate, database field or automatic assessment decision. Browser-graded game attempts remain practice evidence; these facilitator-scored sheets are a separate research preparation task.
